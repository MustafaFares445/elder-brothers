# تقرير تنفيذ لوحة Filament v5

تم تنفيذ لوحة إدارة عربية باتجاه RTL داخل مشروع Elder Brothers مع المحافظة على مسارات واستجابات تطبيق الهاتف الحالية.

## ما تم تنفيذه

- إضافة `filament/filament:^5.0` وتسجيل `AdminPanelProvider`.
- حماية الدخول باستخدام `FilamentUser` وحقلي `is_admin` و`status`.
- Seeder آمن لإنشاء مدير النظام من متغيرات البيئة.
- واجهة عربية RTL ومحتوى ثنائي اللغة عربي/إنجليزي.
- لوحة معلومات بفلاتر مشتركة وإحصائيات ورسوم وجداول تشغيلية.
- إدارة السنوات والمواد والدورات وحالات النشر والأرشفة والنسخ.
- إدارة فيديوهات وملفات الدورة من داخل الدورة.
- إدارة الطلاب وإيقاف الحساب وإلغاء جلساته وأجهزته واشتراكاته وتقدمه.
- إدارة الاشتراكات اليدوية والتمديد والإلغاء وإعادة التفعيل.
- إنشاء أكواد QR بشكل آمن مع حفظ SHA-256 فقط وإظهار الكود الخام مرة واحدة.
- شاشة قراءة فقط لعمليات استرداد QR.
- شاشة قراءة فقط لتقدم مشاهدة الفيديو.
- سير عمل طلبات الدعم والمرفقات والحالات.
- إدارة الصفحات الثابتة بالعربية والإنجليزية.
- سجل إشعارات للقراءة فقط وصفحة حملات إشعارات تعمل عبر Queue.
- صفحة إعدادات للمنصة مرتبطة بنسبة إكمال الفيديو ومدة الروابط المؤقتة وافتراضيات QR وتفعيل التسجيل.
- Policies للموارد ومنع الحذف غير الآمن.
- اختبارات لقواعد دخول اللوحة ونشر الدورة وإنشاء QR.
- وثائق إعداد ونشر محدثة.

## أوامر النشر

```bash
git pull origin main
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan db:seed --class=DashboardSeeder --force
php artisan storage:link
php artisan optimize
php artisan filament:optimize
php artisan queue:restart
```

## إنشاء المدير

أضف إلى `.env`:

```env
ADMIN_NAME="System Administrator"
ADMIN_EMAIL="admin@example.com"
ADMIN_PHONE="+963900000000"
ADMIN_PASSWORD="strong-password"
```

ثم نفذ:

```bash
php artisan db:seed --class=AdminUserSeeder --force
```

تتوفر اللوحة على `/admin`.

## ملاحظات تشغيلية

- يجب تشغيل Queue Worker لإرسال حملات الإشعارات.
- يجب تشغيل Laravel Scheduler لتحديث الاشتراكات المنتهية.
- ملفات الفيديو وملفات الدورات تستخدم التخزين الخاص، والروابط المؤقتة لا تخزن في قاعدة البيانات.
- لا يتم تخزين الكود الخام لـ QR؛ يتم عرضه مرة واحدة فقط عند الإنشاء.
