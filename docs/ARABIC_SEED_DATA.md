# البيانات التجريبية العربية

يقوم `ArabicDemoSeeder` بإنشاء بيانات عربية متكاملة لتجربة تطبيق الهاتف ولوحة Filament.

## التشغيل

```bash
php artisan migrate:fresh --seed
```

أو لتشغيل البيانات العربية فقط:

```bash
php artisan db:seed --class=ArabicDemoSeeder
```

## البيانات المنشأة

- 12 طالبًا بحالات نشطة، غير موثقة، وموقوفة.
- مدير تجريبي في بيئتي `local` و`testing`.
- 4 سنوات دراسية.
- 24 مادة.
- 24 دورة بحالات منشورة، مسودة، ومؤرشفة.
- 96 محاضرة بحالات جاهزة، قيد المعالجة، وفاشلة.
- 48 ملف PDF بمسارات تخزين محلية خاصة.
- اشتراكات نشطة، منتهية، وملغاة.
- تقدم مشاهدة مكتمل وجزئي.
- 8 أكواد QR بحالات نشطة، متوقفة، منتهية، ومستنفدة.
- عمليات استرداد QR مرتبطة بالطلاب والاشتراكات.
- أجهزة وتفضيلات عربية للطلاب.
- 12 طلب دعم موزعة على جميع التصنيفات والحالات.
- 30 إشعارًا عربيًا على الأقل.
- صفحات سياسة الخصوصية، الشروط، والمساعدة.
- إعدادات منصة عربية.

تُخزن جميع الحقول القابلة للترجمة باللغة العربية في المفتاحين `ar` و`en`، حتى لا تظهر نصوص إنجليزية عند تغيير لغة التطبيق أثناء استخدام البيانات التجريبية.

## الحسابات

كلمة المرور لجميع الحسابات التجريبية:

```text
Password123!
```

حساب المدير المحلي:

```text
الهاتف: +963900000000
البريد: admin@elder.local
```

أرقام الطلاب تبدأ من:

```text
+963900000001
```

وتنتهي عند:

```text
+963900000012
```

لا يتم إنشاء المدير التجريبي في بيئة الإنتاج إلا عند إضافة:

```env
SEED_DEMO_ADMIN=true
```

## أكواد QR

```text
ELDER-AR-INDIVIDUAL-001
ELDER-AR-GROUP-002
ELDER-AR-UNLIMITED-003
ELDER-AR-DISABLED-004
ELDER-AR-EXPIRED-005
ELDER-AR-EXHAUSTED-006
ELDER-AR-SINGLE-007
ELDER-AR-CAMPAIGN-008
```

الأكواد الخام مخصصة للاختبار فقط. قاعدة البيانات تحتفظ بالـ SHA-256 والتلميح المقنع، ولا تخزن الكود الخام.
